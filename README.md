# 470 スピントリム道場

470級のシンメトリカル・スピネーカーのトリムを、後輩に教えるためのブラウザ・シミュレーター。

## ねらい

**シートは常に理想的にトリムされている**前提に置く。学習者が動かすのは **ポール高さ** と **ガイ（ポール角）**
の2つだけ。これによって「シートが完璧でも、ポールの位置が悪ければ艇は走らない」という、
実艇でいちばん伝わりにくい因果を切り出して見せる。

## 動かすもの

| 変数 | 範囲 | 意味 |
|---|---|---|
| 真風速 TWS | 2–13 m/s | 海面の風 |
| 走る角度 TWA | 90–175° | 真風向角。ガイの最適値がこれで決まるため必須 |
| トッピング | −12–+38° | ポール仰角。マストアイは固定なので、変わるのは角度 |
| ガイ | 0–90° | 艇首を基準にしたポール角。フォアステイに当たると前へは出せない |

シートは毎フレーム「ラフがカールする直前」を保つよう解かれる。

## モデル

準定常の空力モデル。CFDでも布のシミュレーションでもない。

1. **見かけ風** — TWS・TWA・艇速から AWA / AWS を求める。艇速は力の釣り合いの不動点反復で解くので、
   「速くなると見かけ風が前に回る」フィードバックが入る。
2. **空力係数** — 揚力係数 `CL = 1.45·sin(AWA)`、抗力係数 `CD = 0.30 + 0.95·(1−cos AWA)/2`。
   深い角度ではブラフボディ的に抗力で走る挙動になる。
3. **最適トリム**
   - ポール角： `φ_opt ≒ AWA − 90°`（ポールを見かけ風に直角にする、の幾何学的帰結）
   - ポール仰角： マストアイ（デッキ上 1.00 m）を支点に、トッピングとダウンホールが
     ポール中央を上下させて仰角 θ を変える。タック高さは `1.00 + 2.00·sin θ`。
     目標タック高さは `h_opt = 1.05 + 0.075·(AWS − 4) + 0.006·(AWA − 100)`（クリューと揃う高さ）。
     ポールは3Dベクトルとして扱う。横への張り出しは `1.65·cos θ·sin φ`、
     前への張り出しは `1.65·cos θ·cos φ` で、立てるほどどちらも縮む（ガイとの連動）
   - フォアステイ拘束： ポール長は J に等しい（`POLE = 1.65 m`）。ステムの `x=1.85, z=0.30` から
     ハウンズ `z=5.80` に張られたステイより前へポールは出せないので、仰角ごとに
     **最小ポール角**が決まる。立てるほどタックがステイの細い高さに上がり、前へ出せなくなる。
     「リーチングではポールを下げる」がこの幾何から出てくる
4. **効率** — 最適値からのズレをガウシアンで減点。非対称にしてあり、
   *ガイは前に出しすぎ*、*トッピングは低すぎ* のほうが罪が重い（実艇の感覚に合わせた）。
5. **抵抗** — `R(v) = 14v + 26v² + 1.35v⁴`。プレーニング移行の壁を4次項で近似。

### 限界

因果の向きと相対的な効き方は正しいが、**絶対値は実測ではない**。
係数は470の一般的な艇速レンジ（8kt の風・TWA 140 でおよそ 4kt、16kt で 7kt 前後）に合うよう
定性的に調整したもの。精度を上げるなら実艇の GPS ログと突き合わせて `CFG` の係数を再調整する。

## 3つのビュー

同じ形状の3投影で、タックとクリューの座標を共有している。

- **水平断面（真上から）** — ポール角と、お手本の弦からのズレ
- **後方ビュー（船尾から）** — タックとクリューの高さ差。ポール角が大きい（ランニング）ほど読める
- **側面ビュー（ポートサイド真横）** — 前への張り出しとフォアステイまでの余裕。
  ポール角が小さい（リーチング）ほど読める

後方と側面は排他で、ポール角に応じてどちらが読めるかを画面上でヒントとして出す。

## ファイル

- `spinnaker.html` — 本体。Claude の Artifact として公開する形式（`<head>`/`<body>` のラッパは公開時にホスト側が付ける）
- `build.mjs` — 上記からブラウザで直接開ける `index.html` を生成する
- `index.html` — 生成物。`node build.mjs` で更新する

```
node build.mjs && open index.html
```

外部依存は Google Fonts のみ。ビルドツールもパッケージも不要。
